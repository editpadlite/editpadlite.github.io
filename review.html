EditPad Lite scores 8.0 out of 10 in this review. It is a small Windows text editor with tabs, unlimited undo, regular expression search and very broad encoding support, free for personal use and 24.95 euro per user for work. Its main limits are the 2 GB file cap in the free edition and the tools reserved for EditPad Pro, such as column selection, macros and file comparison.

Verdict

EditPad Lite is a sound choice for people who edit plain text, logs, configuration files and the odd script on Windows and want an editor that handles any encoding without setup. The score rests on the documented feature set, the licence terms and the published limits. No lab tests were run for this review.

It loses points for being Windows only, for charging for work use where several rivals do not, and for keeping everyday tools such as column selection and line sorting in the Pro edition.

Editing and file handling

This EditPad Lite review starts with the basics. The editor opens each file in its own tab and sets no limit on how many files are open at once. Undo and redo are unlimited for every open file and stay available after you save, so saving often does not cut off the path back to an earlier state.

Large files load in the background, so the top and the end of a file can be edited before loading finishes, and there is no hard limit on line length. The free edition handles files up to 2 GB. A licensed copy edits any file that fits in available memory, which is one of the practical reasons to pay. The free versus licensed page lists the others.

The vendor's home page also lists automatic backup and working copies. The release notes for 8.6.0 put the default working copy interval at 5 minutes with a minimum of 1 minute, and note that an empty file no longer produces an empty working copy.

Search and replace

Search lives in a panel docked under the text, not in a floating dialog that covers it. You can switch to a compact toolbar or hide both. The search and replace boxes take multiple lines, and a search can run forward or backward through the current file, the selection or all open files.

Regular expressions use the engine the vendor developed for PowerGREP, with backreferences in the replacement text. Named options include adapt case, which keeps upper, lower and title case when replacing without case sensitivity, and line by line, which acts on the whole line of each match. Matches can be highlighted, cut or copied in one go, and Search History repeats any of the last 16 searches.

Unicode and encodings

Encoding support is the strongest part of the feature list. EditPad Lite edits UTF-8, UTF-16 and UTF-32 directly, along with Windows code pages, ISO 8859 code pages, DOS code pages, classic Mac code pages, KOI8 and several EBCDIC code pages used on IBM mainframes. Convert > Text Encoding converts a file between any two of them, and a file can be reinterpreted when detection guesses wrong.

Windows, UNIX and classic Mac line breaks are kept as they are unless you convert them. Right to left scripts such as Hebrew and Arabic and complex scripts such as the Indic family are supported, with input through any Windows keyboard layout or IME.

Interface and settings

Version 8 brought flat toolbar icons that scale up to 400 percent, a dark theme next to the light one, and colour palettes that include colour blind friendly, solarized and monochrome sets. Syntax colouring covers many languages, among them HTML, C#, Java and Python, and fonts with ligatures such as Fira Code are supported.

Settings are split by file type, so plain text can wrap in a proportional font while source code stays in a fixed font. Menus, toolbars and keyboard shortcuts can be rearranged, and preferences export to an .ini file for the next computer. Full help opens with F1, and a portable copy for a USB stick is one menu command away.

Limits to know before you choose

The vendor's own edition comparison is open about what Lite lacks. Rectangular selections, line sorting, bookmarks, keystroke macros, the file compare tool, the hex editor, search on disk, projects and the FTP client are all in Pro only. The Lite versus Pro comparison has the full list.

The spell checker, the user forum and the Syntax Coloring Scheme Editor need a licensed copy. There is no native build for macOS or Linux. And because free use stops at the office door, a team that wants a no cost editor at work should look at the alternatives to EditPad Lite before settling.

Cost is modest if you do need a licence: pricing starts at 24.95 euro for one user and falls with volume. The installer is 18 MB, and the download page lists the file details and install steps.

Frequently asked questions

Is EditPad Lite a good text editor?

On its documented features, yes for plain text work on Windows. It offers tabs, unlimited undo, regular expression search and support for Unicode and many legacy encodings. It is less suited to people who need column selection, macros or file comparison, which the vendor keeps in EditPad Pro.

Is EditPad Lite safe to download?

The installer is served from the vendor's own download server and the publisher is Just Great Software Co. Ltd., which has sold EditPad since 1996. Get the file only from the official site. Copies on other sites may be outdated or altered.

Does EditPad Lite support regular expressions?

Yes. Search and replace accepts regular expressions and uses the engine the vendor developed for its PowerGREP product. Backreferences can be used in the replacement text, and a replace can run on the current file, the selection or all open files.

Does EditPad Lite have a dark mode?

Yes. Version 8.0.0 added a dark theme for the interface alongside the light one. The editor also ships with many colour palettes, including dark, monochrome, solarized and colour blind friendly sets.

Can EditPad Lite open large files?

The free edition opens files up to 2 GB and loads them in the background, so you can start editing before loading ends. A licensed copy edits files of any size that fit in available memory. Files larger than memory need EditPad Pro.

Does EditPad Lite have a spell checker?

Only in licensed copies. The vendor lists the integrated spell checker as a bonus feature of licensed EditPad Lite and of EditPad Pro, with dictionaries downloaded separately. The free edition for personal use does not include it.
