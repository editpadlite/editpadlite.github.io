How to install

  1. Get the installer from the vendorUse the button on this page to open editpadlite.com and download SetupEditPadLite.exe. Other language editions are linked from the vendor's site.
  2. Run the installerStart the file. Since version 8.0.0, EditPad Lite can be installed per user without administrator rights.
  3. Choose the installation typeClick Immediate Installation for a standard setup. To put the editor on a USB stick instead, use the portable installation button. The portable guide has the details.
  4. Start EditPad LiteOpen the program from its icon. With the default settings it behaves like most Windows text editors, so nothing has to be configured before the first use.
  5. Keep it currentUse Help > Check for New Version from time to time. An update is installed by running the new full installer, and the old version does not have to be removed first.

Trial and licence terms

Paid licences carry a three month money back guarantee, summarised on the refund policy page. Download only from the vendor: copies from file archives can be out of date, and a key from an unofficial source is not a licence.

Frequently asked questions

Is the EditPad Lite download free?

Yes, for personal use. The vendor allows home and school use that earns no income without payment or registration. Use for a job or a business requires a licence, which costs 24.95 euro for one user before tax.

What is the latest version of EditPad Lite?

The vendor's download page lists version 8.6.1, released on 8 April 2026. The release before it was 8.6.0 from 29 October 2025.

Is there a 64 bit EditPad Lite download?

Yes. EditPad Lite 8 is offered in 32 bit and 64 bit builds for Windows XP through Windows 11. The download page lists one installer file of 18 MB for the free edition.

Do I need administrator rights to install EditPad Lite?

Not necessarily. The release notes for version 8.0.0 introduced installation per user without administrator rights. A portable installation on a USB drive is another route when you cannot install software on a computer.

Where do licensed users download EditPad Lite?

Licensed users download their build from the purchased download section of the vendor's download page, listed at 19 MB. One user ID works with every language edition of version 8.

How do I update EditPad Lite?

Choose Help > Check for New Version in the program, or look at the version history on the vendor's site. Then download the full installer and run it. The earlier version does not need to be uninstalled first.
