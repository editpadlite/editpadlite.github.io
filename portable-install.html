EditPad Lite portable: how to put it on a USB drive

EditPad Lite portable is not a separate download. The normal program can copy itself to a USB stick or memory card with one menu command, and the installer can create a portable copy without installing anything on the computer.

To make EditPad Lite portable, insert a removable drive and choose Help > Create Portable Installation, then pick the drive and click Install. The program copies itself and your settings to a folder on the drive and runs from there without changing the host computer. If EditPad Lite is not installed, the installer offers a portable installation button that does the same.

What a portable copy does

EditPad Lite portable means the editor, its settings and its history all live in one folder on a removable drive. When started from there, the program detects the removable media and leaves the host computer alone, apart from files you choose to save. According to the vendor, no DLLs or other dependencies are needed.

This suits people who move between computers, such as a lab, a client site and home, and want the same editor with the same preferences on each. The licence rules do not change with the drive: the personal use rule still decides whether a paid licence is needed.

Before you start

  • A USB stick, memory card or other removable disk with free space. The Install onto Removable Drive screen shows how much is needed.
  • EditPad Lite 8 installed on a Windows computer, or the installer file from the vendor. The download page lists the file.
  • A host computer running a supported Windows version. See the system requirements.
  • If the device is an external hard disk, expect Windows to report it as a fixed drive. Step 3 covers that case.

Create the portable copy from an installed EditPad Lite

  1. Insert the driveConnect the USB stick, memory card or other removable disk and wait for Windows to show it.
  2. Open Create Portable InstallationIn EditPad Lite, open the Help menu and choose Create Portable Installation. The Install onto Removable Drive screen opens and lists the drives that Windows reports as removable.
  3. Handle drives reported as fixedIf your external hard disk is missing from the list, turn on the option to treat all drives as removable. EditPad then writes a file named RemovableDrive.sys to the destination drive, which tells the program not to modify the host computer.
  4. Choose the parts to copyThe main application is always copied. Optional parts are the help file, the syntax coloring schemes, the file navigation schemes and any spell checker dictionaries you installed.
  5. Select the drive and click InstallPick the target device. A label shows the disk space required and the parts being copied. Click Install, and the screen closes by itself when the copy is finished.
  6. Run it on another computerOn the other computer, open the EditPad Lite folder on the drive in Windows Explorer, named EditPadLite8 in the user's guide, and double click the EditPad Lite program file.

Create it from the installer instead

If EditPad Lite is not installed, download the installer and use its portable installation button in place of a normal install. The user's guide notes that this route works even without permission to install software on the computer.

The user's guide, which covers both EditPad editions, adds that the result depends on the Windows you run the installer on. On 32 bit Windows it creates a 32 bit copy that runs on both 32 bit and 64 bit Windows. On 64 bit Windows it creates a 64 bit copy that runs on 64 bit Windows only, unless you pass the /32 parameter to the installer.

Since version 8.5.4 the installer also accepts a /portable parameter, which creates a silent portable installation in a folder you name. That is useful for preparing several drives in a row.

Limits of a portable copy

The vendor's pages do not describe portable use on network drives or cloud folders. For a view of what the editor offers once it is running, see the EditPad Lite review.

  • The Preferences screen has no Shortcuts page.
  • In Configure File Types, the buttons on the Definition page that create and remove file associations are disabled.
  • Running the command again never deletes files from the device, so parts you deselect stay where they are.
  • Stored file paths are updated to the drive's current letter each time EditPad starts.
  • The whole folder can be moved into another parent folder on the device.

Get the installer first

Both routes start with the official installer: install and use the Help menu, or run the installer and pick the portable option.

Frequently asked questions

Is there a portable version of EditPad Lite?

There is no separate portable download. The standard EditPad Lite creates a portable copy through Help > Create Portable Installation, and the installer has a portable installation button. Both place the editor and its settings on a removable drive.

Where does portable EditPad Lite store its settings?

Settings and history are stored in the same folder as the program on the removable drive. The user's guide names the folder EditPadLite8, placed off the root of the device. The folder can be moved into another parent folder on the same device.

Can I make a portable copy without installing EditPad Lite?

Yes. Run the installer and choose its portable installation button instead of a normal installation. The user's guide says this works without permission to install software on the computer.

Does portable EditPad Lite change the host computer?

No, apart from files you save yourself. When started from a removable drive, the program detects this and does not modify the host computer. A portable copy also cannot create file associations or shortcuts.

Why is my external drive not listed?

The Install onto Removable Drive screen lists only drives that Windows reports as removable, and external hard disks are often reported as fixed. Turn on the option to treat all drives as removable. EditPad then creates a RemovableDrive.sys file on that drive.

Do I need a licence for a portable copy?

The same rule applies as for an installed copy. Personal use at home or school that earns no income is free, and use for a job or business needs a licence. A single user licence covers all the computers one person uses.
