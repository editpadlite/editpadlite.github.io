EditPad Lite system requirements: Windows versions, Linux and Mac

The EditPad Lite system requirements are short: any desktop Windows from XP to 11, in 32 bit or 64 bit. The vendor publishes no processor, memory or disk figures, and offers no native build for Mac or Linux.

EditPad Lite 8 runs on Windows XP, Vista, 7, 8, 8.1, 10 and 11, in both 32 bit and 64 bit versions. The vendor does not publish minimum processor, memory or disk space figures, and the installer is listed at 18 MB. There is no native Linux or macOS version, but the vendor documents running the Windows version on Linux through Wine.

Supported Windows versions

The EditPad Lite system requirements on the vendor's download page name operating systems only. Version 8.x supports every desktop release from Windows XP to Windows 11, in 32 bit and 64 bit builds.

Processor, memory and disk space

The vendor does not publish minimum processor, memory or disk space requirements for EditPad Lite, so none are quoted here. The only size on its pages is the installer: 18 MB for the free download and 19 MB for the purchased one.

Memory matters in one documented way. The free edition opens files up to 2 GB, while a licensed copy edits files of any size that fit in available memory. Files larger than memory are a feature of EditPad Pro. The free versus licensed page covers that split.

High resolution screens are addressed in the release notes: version 8.0.0 introduced toolbar icons that scale up to 400 percent.

Linux through Wine

There is no Linux version of EditPad Lite 8. The vendor instead documents running the Windows version under Wine and reports that it works on 64 bit Ubuntu apart from a few minor glitches.

  1. Install Wine from your distribution's package manager, or from winehq.org if it is not offered there.
  2. Download the EditPad Lite installer and open it with Wine, or run it from a terminal with the wine command.
  3. Click the Immediate Installation button.
  4. Start EditPad Lite from the desktop icon.

The vendor recommends three settings on Linux under Options > Configure File Types: set the default line break style to Linux (LF only), set the default encoding to UTF-8 or an ISO 8859 code page, and turn off writing the byte order marker. Known gaps are right to left and complex scripts, which Wine does not lay out properly, and the help file, which needs Wine's Gecko library.

If a native Linux editor matters more than this particular one, the alternatives page lists editors that run there.

macOS

The vendor's pages do not mention macOS at all, either natively or through Wine. Mac users should treat EditPad Lite as unsupported on their system and choose another editor.

Older Windows versions and locked down computers

For Windows 2000 the vendor keeps EditPad Lite 7.6.7 of 10 December 2019 available in the purchased download section. That version supports Windows 2000 through Windows 10. EditPad Lite 6 is the version the vendor names for Windows 98, ME and NT4.

A computer you cannot install software on is not a blocker either: a portable installation runs from a USB stick. For a normal setup, the download page has the steps, and work computers need a licence at the prices listed here.

Check it on your own Windows

The installer is 18 MB and personal use is free, so the quickest compatibility check is to install it.

Frequently asked questions

Does EditPad Lite work on Windows 11?

Yes. The vendor lists Windows 11 among the supported systems for EditPad Lite 8, along with Windows 10, 8.1, 8, 7, Vista and XP. Both 32 bit and 64 bit versions of Windows are supported.

Does EditPad Lite still run on Windows 7 and XP?

Yes. EditPad Lite 8.6.1, released on 8 April 2026, is listed for Windows XP, Vista and 7 as well as later versions. For Windows 2000 the vendor offers the older version 7.6.7 in its purchased download section.

Is there a 64 bit version of EditPad Lite?

Yes. EditPad Lite 8 comes in 32 bit and 64 bit builds. The vendor's download page lists a single installer file for the free edition.

Does EditPad Lite run on a Mac?

No native macOS version exists, and the vendor's pages do not describe any way to run it on a Mac. Mac users should pick a different editor.

Does EditPad Lite run on Linux?

Not natively. The vendor documents running the Windows version through Wine and reports that it works on 64 bit Ubuntu with minor glitches. Right to left and complex scripts do not behave properly under Wine.

How much RAM and disk space does EditPad Lite need?

The vendor does not publish memory, processor or disk space requirements. The installer is listed at 18 MB. Memory limits the file size a licensed copy can open, while the free edition stops at 2 GB.
